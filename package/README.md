# aux4 encrypter

aux4 encrypter is an encryption tool that uses AES-256-CBC algorithm to encrypt and decrypt text.

## Generate IV and SECRET

Before encrypt or decrypt, you need an initialization vector (IV) and a secret key (SECRET). 

The IV can be randomly generated by the tool, it must be 16 bytes long string.

```bash
> aux4 encrypter generate-secret --length 16
```
```text
nhBGMMMQDJeMncEs
```

The SECRET can be randomly generated by the tool, it must be 16, 24, or 32 bytes long string.

```bash
> aux4 encrypter generate-secret --length 32
```
```text
9j48xBeBCQeV7R6Gnhe1V3acoBSS7ile
```

## Encrypt

### Using parameter

```bash
> aux4 encrypter encrypt --iv nhBGMMMQDJeMncEs --secret 9j48xBeBCQeV7R6Gnhe1V3acoBSS7ile --text "Hello World"
```
```text
9V3GJr82MrlrEpZKyUF5OA==
```

### Using Environment Variables

```bash
> export AUX4_IV=nhBGMMMQDJeMncEs
```
```bash
> export AUX4_SECRET=9j48xBeBCQeV7R6Gnhe1V3acoBSS7ile
```
```bash
> aux4 encrypter encrypt --text "Hello World"
```
```text
9V3GJr82MrlrEpZKyUF5OA==
```

### Using aux4/config

```bash
> aux4 aux4 pkger install aux4/config
```
```bash
> echo 'config:' > config.yaml
```
```bash
> aux4 config set --name myApp/iv --value nhBGMMMQDJeMncEs
```
```bash
> aux4 config set --name myApp/secret --value 9j48xBeBCQeV7R6Gnhe1V3acoBSS7ile
```
```bash
> aux4 encrypter encrypt --config myApp --text "Hello World"
```
```text
9V3GJr82MrlrEpZKyUF5OA==
```

### Encrypt File

```bash
> echo "Hello World" > hello.txt
```
```bash
> cat hello.txt | aux4 encrypter encrypt 
```
```text
9V3GJr82MrlrEpZKyUF5OA==
```
